# SAST thresholds for slicingpie (gh-pie)
#
# Reference values for `make sast`. The SAST runner compares metrics to these
# rows and prints OK / WARN / FAIL. Any FAIL makes `make sast` exit 1.
#
# Tool versions come from pyproject.toml [dependency-groups] dev and uv.lock.

# ---------------------------------------------------------------------------
# Metric              Tool              How it is computed
# ---------------------------------------------------------------------------
# Test coverage       pytest + pytest-cov  pytest runs the test suite; coverage
#                                          measures executed lines/branches in
#                                          package `slicingpie` (see pyproject
#                                          [tool.coverage.run]).
#
# LOC                 radon (raw)          radon raw src/slicingpie -s
#                                          LOC = physical lines; SLOC = source
#                                          lines without blanks/comments;
#                                          LLOC = logical lines.
#
# Cyclomatic          radon (cc)           radon cc src/slicingpie -a -s
# complexity                               McCabe complexity per function/method;
#                                          ranks A-E (1-5, 6-10, 11-20, ...).
#
# Cognitive           complexipy           complexipy on each .py under
# complexity                               src/slicingpie (excludes sast.py);
#                                          nested control flow, similar to
#                                          Sonar "cognitive complexity".
#
# Maintainability     radon (mi)           radon mi src/slicingpie -s
# index (MI)                               0-100 scale; rank A (>=20) is healthy
#                                          for Python in radon's scale.
#
# Duplicate code      pylint               pylint --enable=duplicate-code only;
#                                          counts R0801 duplicate-code messages.
#
# Security            bandit               bandit -r src/slicingpie (excludes
#                                          sast.py); severity HIGH/MEDIUM/LOW.
#
# Dead code           vulture              vulture on source files, min confidence
#                                          80% (unused defs/imports).

# ---------------------------------------------------------------------------
# Thresholds (reasonable for a small CLI library)
# ---------------------------------------------------------------------------
# Format: metric | target | warn | fail | notes

test_coverage_statements | >= 80%  | < 80%  | < 70%  | Primary gate; current suite target.
test_coverage_branches   | >= 75%  | < 75%  | < 65%  | Shown in make sast notes when enabled.

loc_total                | info    | -      | -      | No hard cap; track growth over time.
loc_sloc_per_file        | <= 350  | > 400  | > 500  | Split large modules (e.g. github client).

cyclomatic_avg           | <= 6    | > 8    | > 10   | Across all measured blocks (radon cc).
cyclomatic_max_function  | <= 15   | rank C | rank D | Single function; rank D/E = refactor.

cognitive_avg            | <= 8    | > 10   | > 12   | complexipy average over functions.
cognitive_max_function   | <= 15   | > 20   | > 25   | Matches common Sonar-style limits.

maintainability_min_file | >= 20   | 10-19  | < 10   | Per-file MI (radon rank A / B / C).
maintainability_avg      | >= 45   | 35-44  | < 35   | Repo-wide average MI.

duplicate_code_blocks    | 0       | >= 1   | >= 3   | pylint duplicate-code count.

bandit_high              | 0       | >= 1   | >= 1   | Must fix before release.
bandit_medium            | 0       | >= 1   | >= 2   | Fix or document nosec with reason.
bandit_low               | 0       | > 3    | > 5    | Often i18n false positives; review each.

vulture_confidence_80    | 0       | >= 1   | >= 3   | Unused code at >= 80% confidence.

# ---------------------------------------------------------------------------
# Quick mapping: make sast "Summary" row -> tool
# ---------------------------------------------------------------------------
# Test coverage          -> pytest-cov
# LOC                    -> radon raw
# Cyclomatic complexity  -> radon cc
# Cognitive complexity   -> complexipy
# Maintainability index  -> radon mi
# Duplicate code         -> pylint (duplicate-code)
# Security (bandit)      -> bandit
# Dead code (vulture)    -> vulture
